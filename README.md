# Zomato Restaurant Analytics Dashboard

## Project Overview
This project presents an interactive Power BI dashboard for analyzing Zomato restaurant data. It helps explore restaurant distribution, cuisines, pricing, and service availability.

## Project Objectives
- Analyze the total number of restaurants.
- Explore restaurants by city and cuisine.
- Understand price range distribution.
- Analyze online delivery and table booking availability.
- Explore restaurant locations using a map, if available.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (for calculations, where applicable)
- CSV Dataset
- GitHub

## Dashboard Features
- Restaurant Overview
- Restaurant and Cuisine Analysis
- City and Services Analysis
- KPI Cards
- Bar, Donut and Pie Charts
- Slicers and Filters
- Map Visualization, if included



## Conclusion
This project demonstrates how Power BI can be used to analyze restaurant data and present useful insights through interactive visualizations.
