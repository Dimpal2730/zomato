
# Zomato Restaurant Analytics Dashboard

## 📌 Project Overview

The **Zomato Restaurant Analytics Dashboard** is a data analytics project developed using Microsoft Power BI. The project focuses on analyzing restaurant data to understand restaurant distribution across cities, cuisine varieties, price ranges, average cost for two people, online delivery, and table booking availability.


## 🎯 Project Objectives

- To analyze restaurant data using Power BI.
- To identify the total number of restaurants and cuisines.
- To analyze restaurant distribution across different cities.
- To study different cuisines offered by restaurants.
  
## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculations and measures
- **CSV Dataset** – Restaurant data source
- **GitHub** – Project storage and documentation
- **HTML & CSS** – Project information webpage
## 📊 Dashboard Features

- **Restaurant Overview:** Displays key restaurant statistics using KPI cards.
- **City Analysis:** Shows the number of restaurants in different cities.
- **Cuisine Analysis:** Analyzes restaurant distribution by cuisine.
- **Price Range Analysis:** Compares restaurants based on price range.
- **Average Cost Analysis:** Displays the average cost for two people.
- **Online Delivery Analysis:** Shows online delivery availability.
- **Table Booking Analysis:** Analyzes table booking availability.
- **Interactive Slicers:** Allows users to filter and explore restaurant data.
- **Data Visualization:** Uses bar charts, donut charts, cards, tables, and maps where applicable.
- **Interactive Dashboard:** Helps users explore restaurant data and understand key patterns.

## 🚀 How to Use

1. Download or clone this GitHub repository to your computer.
2. Download and extract the required CSV dataset.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. If required, update the CSV file path in Power BI.
5. Click **Refresh** to load the latest data.
6. Explore the dashboard using charts, filters, and slicers.
7. Analyze restaurant distribution, cuisines, pricing, and service availability.
